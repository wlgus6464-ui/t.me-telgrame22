GitHub 연결 설정

저장하려면 GitHub 비밀 키가 필요합니다. 이 키는 이 브라우저 안에만 저장되고, GitHub 에 저장할 때만 쓰입니다.

GitHub 비밀 키 · github_pat_ 로 시작합니다
칸을 비워 두면 노바덱스 관리자 페이지에 넣어 둔 키를 같이 씁니다.
노바덱스 키에 이 저장소 추가하는 법 (키를 이미 만들었다면)
  1. GitHub 에 로그인한 상태에서 비밀 키 목록을 엽니다.
  2. 노바덱스 때 만든 키 이름(예: NovaDEX 관리자)을 누르고 Edit 을 누릅니다.
  3. Repository access 의 Only select repositories 에서 t.me-telgrame22 를 더 고릅니다.
  4. 맨 아래 Update 를 누릅니다. 키 글자는 그대로라서 여기에 다시 넣지 않아도 됩니다.
새 비밀 키 만드는 법
  1. GitHub 에 로그인한 상태에서 비밀 키 만들기 화면을 엽니다.
  2. Token name 칸에 텔레그램 관리자 라고 적습니다.
  3. Expiration 에서 기간을 고릅니다 (예: 1년).
  4. Repository access 에서 Only select repositories 를 누르고 t.me-telgrame22 를 고릅니다.
  5. Permissions 에서 Contents 를 Read and write 로 바꿉니다.
  6. 맨 아래 초록 버튼 Generate token 을 누르고, 나온 키를 복사해 위 칸에 붙여넣습니다.
