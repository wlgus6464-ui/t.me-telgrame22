# 김지현 관점방 홈페이지

## 글 수정하는 법 (관리자 페이지)

https://wlgus6464-ui.github.io/t.me-telgrame22/admin.html 을 엽니다.

- 왼쪽 칸이나 오른쪽 미리보기 화면을 눌러 고칩니다. 미리보기의 글은 그 자리에서 바로 고쳐도 됩니다.
- 하트·좋아요·조회수·시간, 날짜 칸, 채널 이름·구독자 줄·프로필 사진, 글 사진(Ctrl+V 붙여넣기·끌어다 놓기)을 고칠 수 있습니다.
- ＋ 아래에 글 / ＋ 아래에 날짜 로 새 칸을 넣고, ↑ ↓ 로 순서를 바꾸고, 🗑 로 지웁니다.
- 💾 저장(Ctrl+S)을 누르면 1~2분 뒤 홈페이지에 바뀝니다. 바뀌면 알림이 뜹니다.
- 처음 한 번 ⚙ 연결 설정에 GitHub 비밀 키를 넣어야 저장됩니다. 노바덱스 관리자 페이지에 넣어 둔 키가 있으면 같이 씁니다
  (그 키에 이 저장소 권한이 없으면 연결 설정 창의 안내대로 추가).

## 직접 고치는 법 (예전 방식)

홈 화면 채팅은 `index.html`이 아니라 **`chats.js`** 에서 고칩니다.

1. GitHub 저장소에서 `chats.js` 클릭
2. 연필(Edit) 아이콘 클릭
3. 글 내용만 바꾸고 Commit changes

채널 이름, 소개, 링크는 파일 위쪽 `window.SITE` 를 고치세요.
채팅 하나하나는 아래쪽 `window.CHATS` 배열에서 고치세요.

새 채팅을 추가하려면 `{ type: "post", ... }` 덩어리를 복사해 붙이면 됩니다.
